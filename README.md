# Customer-Behavior-Data-Analytics

Developed a corporate-level end-to-end data analytics project simulating real-world retail workflows to analyze
customer shopping patterns, demographic trends, and loyalty.
• Data Cleaning & EDA (Python/Pandas): Performed exploratory data analysis, handled missing values by imputing
category-specific medians to eliminate bias, standardized column names to snake_case, and conducted feature
engineering (creating age groups and numerical purchase frequency columns).
• Database Management & Advanced SQL Analysis (PostgreSQL): Loaded and managed tabular datasets via
SQLAlchemy, writing complex queries involving CTEs, window functions (ROW_NUMBER()), subqueries, and
aggregations to uncover key business insights (e.g., gender revenue split, high-value discounted purchases, and topselling products by category).
• Interactive Dashboarding (Power BI): Designed a sleek, executive-ready interactive Power BI dashboard featuring
custom measures, card visuals, donut charts, bar charts, and dynamic cross-filtering slicers to track KPIs like total
revenue, average spend, and subscription status
